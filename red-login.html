⚠️ Una cosa importante antes de probar En tu archivo actual tenés: import { auth } from "./Js/firebase.js"; Eso significa que "firebase.js" tiene que estar dentro de una carpeta llamada "Js", por ejemplo: GESBASE/ ├── red.html ├── red-login.html ├── red-registro.html ├── conexiones.html └── Js/ ├── firebase.js └── firebase-config.js Pero en la conversación anterior también me mostraste "firebase.js" y "firebase-config.js" como archivos que podrían estar en la raíz. Si están en la raíz, la línea correcta es: import { auth } from "./firebase.js"; y no: import { auth } from "./Js/firebase.js"; Ese detalle por sí solo puede hacer que el botón de iniciar sesión no haga absolutamente nada. Probemos primero este login. Si al tocar Iniciar sesión aparece un mensaje de error, pasámelo exactamente como aparece y corregimos el siguiente punto.
